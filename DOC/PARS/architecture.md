# Архитектура модуля PARS

## 1. Общее описание
PARS — React + Vite приложение для анализа и парсинга данных из API ВКонтакте (VK).

## 2. State Management
- **PostsStoreContext**: Централизованный стор.
- **Persistence**: Полная персистентность через `localStorage` (все состояния, включая настройки, историю экспорта и правки постов).

## 3. Ядро (lib/)
- `vk-api-client.ts`: VK API клиент, работающий с токенами доступа.
- `vk-utils.ts`: Нормализация входящего JSON от парсера.
- `price-utils.ts`: Расчет цен (формулы наценки, округления).
- `csv-exporter.ts`: Генерация CSV отчетов.

## 4. Конфигурация (PriceConfig)
Архитектура поддерживает гибкую настройку цен:
- Типы наценок: проценты или фикс.
- Округление: `floor`, `ceil`, `round`, `to_9`.
- Валюты: USD, EUR, KZT, UE.

## 5. Методы интеграции
- `fetchOnlineWall`: Загрузка постов напрямую из VK.
- `exportSelectedPostsToVk`: Потоковая выгрузка постов в целевые сообщества с логгированием.
- `importJson`: Импорт сохраненного JSON с обогащением локальными правками.

## 6. Механика правок
Локальные правки (текст, цена) хранятся в `editsMap` (localStorage). При каждом обновлении `PriceConfig` посты автоматически пересчитываются, если правка цены не была сделана вручную.

## 7. Механика обратного импорта из Excel/CSV
Для бесшовного импорта отредактированных куратором данных из Excel (CSV) заложена следующая логика:
- **Ключ сопоставления**: `post_id` (уникальный ID в формате `owner_id_id`).
- **Точка интеграции**: Слияние изменений с `editsMap` в локальном хранилище. Исходные данные постов не перезаписываются.
- **Жёсткая валидация**: Файл должен обязательно содержать колонки `ID Поста`, `Отредактированный текст` и `Итоговая цена (₽)`.
- **Разрешение конфликтов**: При совпадении `post_id` данные из файла перезаписывают локальные правки с предупреждением в UI. Пустые ячейки в файле игнорируются (существующие правки не затираются).
- **Безопасность парсинга**: Использование потокового разбора кавычек, экранирования `""` и спецсимволов переноса строк (`\n`) согласно RFC 4180 (рекомендуется PapaParse).
- **Производительность**: Применение bulk-обновления в сторе (`bulkUpdatePostDetails`) для минимизации ререндеров React при обновлении тысяч постов.
