## 🧠 1. Алгоритм группировки фото из одного поста

### 1.1. Постановка задачи

**Проблема:** Один пост поставщика может содержать 1–10 фотографий одного товара. При парсинге стены VK API возвращает массив вложений. Необходимо объединить их в **одну карточку товара**, а не создавать 10 отдельных.

**Цель:** Сохранить целостность товара (описание + все фото) для удобства редактирования и выгрузки.

### 1.2. Логика группировки

```python
# === parsers/grouping_engine.py ===
from typing import List, Dict
from collections import defaultdict
import hashlib

class PostGrouper:
    """Движок группировки фото из одного поста"""
    
    @classmethod
    def get_group_key(cls, post_data: Dict) -> str:
        """
        Формирование уникального ключа группы.
        Приоритет: post_id > content_hash > image_hash
        """
        # Вариант 1: Идеальный — есть ID поста от VK API
        if 'post_id' in post_data and 'owner_id' in post_data:
            return f"{post_data['owner_id']}_{post_data['post_id']}"
        
        # Вариант 2: Хеш контента (текст + дата)
        content = f"{post_data.get('text', '')}{post_data.get('date', '')}"
        return hashlib.md5(content.encode()).hexdigest()
    
    @classmethod
    def group_posts(cls, raw_posts: List[Dict]) -> List[Dict]:
        """
        Группировка сырых данных постов.
        Возвращает список сгруппированных записей.
        """
        groups = defaultdict(lambda: {
            'post_id': None,
            'owner_id': None,
            'text': '',
            'date': None,
            'images': [],
            'price': None,
            'source_url': None,
            'is_grouped': False
        })
        
        for post in raw_posts:
            key = cls.get_group_key(post)
            group = groups[key]
            
            # Заполняем базовые данные (из первого поста в группе)
            if not group['post_id']:
                group['post_id'] = post.get('post_id')
                group['owner_id'] = post.get('owner_id')
                group['text'] = post.get('text', '')
                group['date'] = post.get('date')
                group['source_url'] = cls._build_vk_url(post)
                group['is_grouped'] = False
            
            # Добавляем изображения в общую кучу
            if 'attachments' in post:
                for attach in post['attachments']:
                    if attach['type'] == 'photo':
                        photo = attach['photo']
                        group['images'].append({
                            'url': cls._get_max_res_photo_url(photo),
                            'width': photo.get('width', 0),
                            'height': photo.get('height', 0),
                            'vk_photo_id': f"{photo['owner_id']}_{photo['id']}"
                        })
                        group['is_grouped'] = len(group['images']) > 1
            
            # Извлекаем цену из текста (первое вхождение)
            if group['price'] is None:
                group['price'] = PriceEngine.extract_price(post.get('text', ''))
        
        return list(groups.values())
    
    @staticmethod
    def _build_vk_url(post: Dict) -> str:
        """Формирование ссылки на пост ВКонтакте"""
        owner_id = post.get('owner_id', '')
        post_id = post.get('post_id', '')
        # Для групп owner_id отрицательный, в URL нужен без минуса
        owner_display = abs(int(owner_id)) if owner_id else ''
        return f"https://vk.com/wall{owner_display}_{post_id}"
    
    @staticmethod
    def _get_max_res_photo_url(photo: Dict) -> str:
        """
        Получение URL фото в максимальном разрешении.
        VK API возвращает массив sizes, выбираем наибольший.
        """
        sizes = photo.get('sizes', [])
        if not sizes:
            return photo.get('photo_604', '')  # Fallback
        
        # Сортируем по ширине, берём максимальный
        max_size = max(sizes, key=lambda s: s.get('width', 0))
        return max_size.get('url', '')
```

### 1.3. Сценарии группировки

| Сценарий | Поведение | Пример |
|----------|-----------|--------|
| **Стена, 1 фото** | `is_grouped = False` | Обычная карточка |
| **Стена, 3 фото** | `is_grouped = True`, все в одной карточке | Свайп внутри карточки |
| **Альбом** | По умолчанию `is_grouped = False` (каждое фото отдельно) | Можно включить группировку по названию альбома |
| **Репост с фото** | Группировка по ID репоста, текст берётся из оригинала | Сохраняется ссылка на источник |
| **Товары (Market)** | Не группируются, у каждого товара свой ID | Структурированные данные |

## 🔍 2. Regex-паттерны для извлечения цены

### 2.1. Постановка задачи

**Проблема:** Поставщики пишут цены в разных форматах: `1500р`, `1 500 руб.`, `1500₽`, `500-700`, `$50`, `50 у.е.`

**Цель:** Извлечь **числовое значение в рублях** с максимальной точностью, поддержать валюты и диапазоны.

### 2.2. Класс извлечения цены

```python
# === editors/price_engine.py ===
import re
from typing import Optional, Tuple, List
from dataclasses import dataclass

@dataclass
class PriceResult:
    value: float
    currency: str
    is_range: bool
    range_min: Optional[float] = None
    range_max: Optional[float] = None
    raw_match: str = ""

class PriceEngine:
    """Движок извлечения и нормализации цен"""
    
    # === Паттерны ===
    
    # Основная цена: 1500, 1 500, 1.500, 1500.00
    NUMBER_PATTERN = r'(\d{1,3}(?:[\s\.]?\d{3})*(?:\.\d{1,2})?)'
    
    # Валюты и обозначения
    CURRENCY_PATTERN = r'(руб\.?|р\.?|₽|rub|RUB|USD|\$|EUR|€|у\.?е\.?|тенге|₸)'
    
    # Полный паттерн цены
    PRICE_FULL_PATTERN = re.compile(
        rf'{NUMBER_PATTERN}\s*{CURRENCY_PATTERN}',
        re.IGNORECASE
    )
    
    # Диапазон цен: 500-700, 500 до 700, 500-700р
    PRICE_RANGE_PATTERN = re.compile(
        rf'{NUMBER_PATTERN}\s*[-–—до]\s*{NUMBER_PATTERN}\s*{CURRENCY_PATTERN}?',
        re.IGNORECASE
    )
    
    # Цена с опт/розница: 1500/опт, 1500 (розница 2000)
    PRICE_WHOLESALE_PATTERN = re.compile(
        rf'{NUMBER_PATTERN}\s*/\s*(опт|оптовая|wholesale)',
        re.IGNORECASE
    )
    
    # Валюты с курсом (конфигурируется)
    EXCHANGE_RATES = {
        'USD': 85.0,
        'EUR': 92.0,
        'RUB': 1.0,
        'KZT': 0.19,  # Тенге
        'UE': 85.0    # Условные единицы
    }
    
    @classmethod
    def extract_price(cls, text: str) -> Optional[PriceResult]:
        """
        Извлечение цены из текста.
        Приоритет: диапазон → основная цена → опт-цена
        """
        if not text:
            return None
        
        # 1. Пробуем найти диапазон (500-700р)
        range_match = cls.PRICE_RANGE_PATTERN.search(text)
        if range_match:
            return cls._parse_range(range_match, text)
        
        # 2. Основная цена (1500₽)
        price_match = cls.PRICE_FULL_PATTERN.search(text)
        if price_match:
            return cls._parse_single(price_match, text)
        
        # 3. Опт-цена (1500/опт)
        wholesale_match = cls.PRICE_WHOLESALE_PATTERN.search(text)
        if wholesale_match:
            return cls._parse_wholesale(wholesale_match, text)
        
        return None
    
    @classmethod
    def _parse_single(cls, match: re.Match, full_text: str) -> PriceResult:
        """Парсинг одиночной цены"""
        raw_value = match.group(1).replace(' ', '').replace('.', '')
        currency = match.group(2).lower()
        value = float(raw_value)
        
        # Конвертация в рубли
        value_rub = cls._convert_to_rub(value, currency)
        
        return PriceResult(
            value=value_rub,
            currency='RUB',
            is_range=False,
            raw_match=match.group(0)
        )
    
    @classmethod
    def _parse_range(cls, match: re.Match, full_text: str) -> PriceResult:
        """Парсинг диапазона цен — берём минимальное значение"""
        raw_min = match.group(1).replace(' ', '').replace('.', '')
        raw_max = match.group(2).replace(' ', '').replace('.', '')
        
        # Пытаемся найти валюту в тексте рядом
        currency_match = cls.CURRENCY_PATTERN.search(full_text[match.start():match.end()])
        currency = currency_match.group(1).lower() if currency_match else 'rub'
        
        min_val = float(raw_min)
        max_val = float(raw_max)
        
        # Конвертация
        min_rub = cls._convert_to_rub(min_val, currency)
        
        return PriceResult(
            value=min_rub,  # Берём минимум для безопасности
            currency='RUB',
            is_range=True,
            range_min=min_rub,
            range_max=cls._convert_to_rub(max_val, currency),
            raw_match=match.group(0)
        )
    
    @classmethod
    def _parse_wholesale(cls, match: re.Match, full_text: str) -> PriceResult:
        """Парсинг опт-цены"""
        raw_value = match.group(1).replace(' ', '').replace('.', '')
        value = float(raw_value)
        
        return PriceResult(
            value=value,
            currency='RUB',
            is_range=False,
            raw_match=match.group(0)
        )
    
    @classmethod
    def _convert_to_rub(cls, value: float, currency: str) -> float:
        """Конвертация валюты в рубли по заданным курсам"""
        currency = currency.lower()
        
        rate_map = {
            'руб': 1.0, 'р': 1.0, '₽': 1.0, 'rub': 1.0, 'r': 1.0,
            'usd': cls.EXCHANGE_RATES['USD'], '$': cls.EXCHANGE_RATES['USD'],
            'eur': cls.EXCHANGE_RATES['EUR'], '€': cls.EXCHANGE_RATES['EUR'],
            'у.е.': cls.EXCHANGE_RATES['UE'], 'уе': cls.EXCHANGE_RATES['UE'],
            'тенге': cls.EXCHANGE_RATES['KZT'], '₸': cls.EXCHANGE_RATES['KZT']
        }
        
        rate = rate_map.get(currency, 1.0)  # По умолчанию считаем рубли
        return round(value * rate, 2)
    
    @classmethod
    def find_all_prices(cls, text: str) -> List[PriceResult]:
        """Найти все цены в тексте (для отладки и множественных товаров в посте)"""
        results = []
        for match in cls.PRICE_FULL_PATTERN.finditer(text):
            results.append(cls._parse_single(match, text))
        return results
```

### 3.1. Постановка задачи

**Проблема:** При повторном парсинге той же группы те же посты не должны обрабатываться заново. Нужно отслеживать:
- Уже выгруженные посты
- Дубликаты контента
- Историю изменений цены/текста

**Цель:** Избежать дублирования контента и лишних запросов к API.

### 3.3. Логика хеширования и проверки дубликатов

```python
# === cache/duplicate_tracker.py ===
import hashlib
import json
from typing import Optional, List
from datetime import datetime
import asyncpg  # или sqlalchemy, на выбор команды

class DuplicateTracker:
    """Отслеживание обработанных постов и дубликатов"""
    
    def __init__(self, db_connection_string: str):
        self.db_url = db_connection_string
        self.pool = None
    
    async def initialize(self):
        """Инициализация пула соединений"""
        self.pool = await asyncpg.create_pool(self.db_url, max_size=10)
    
    @staticmethod
    def compute_post_hash(post_data: dict) -> str:
        """
        Вычисление хеша поста для уникальной идентификации.
        Учитывает: owner_id, post_id, date, text (первые 500 символов)
        """
        content = json.dumps({
            'owner_id': post_data.get('owner_id'),
            'post_id': post_data.get('post_id'),
            'date': post_data.get('date'),
            'text_preview': (post_data.get('text', '')[:500]).strip()
        }, sort_keys=True)
        return hashlib.sha256(content.encode()).hexdigest()
    
    @staticmethod
    def compute_text_hash(text: str) -> str:
        """Хеш текста для отслеживания изменений описания"""
        return hashlib.md5(text.strip().encode()).hexdigest()
    
    async def is_post_processed(self, post_hash: str, vk_post_id: str, owner_id: str) -> bool:
        """
        Проверка: обрабатывался ли уже этот пост.
        Возвращает True если пост найден в БД.
        """
        async with self.pool.acquire() as conn:
            row = await conn.fetchrow(
                """
                SELECT id, is_exported, last_parsed_at 
                FROM processed_posts 
                WHERE post_hash = $1 OR (vk_post_id = $2 AND owner_id = $3)
                """,
                post_hash, vk_post_id, owner_id
            )
            return row is not None
    
    async def get_post_status(self, vk_post_id: str, owner_id: str) -> Optional[dict]:
        """
        Получить статус поста (для отображения в UI).
        Возвращает данные о выгрузке или None.
        """
        async with self.pool.acquire() as conn:
            row = await conn.fetchrow(
                """
                SELECT is_exported, export_targets, exported_at, price_edited
                FROM processed_posts
                WHERE vk_post_id = $1 AND owner_id = $2
                """,
                vk_post_id, owner_id
            )
            if row:
                return dict(row)
            return None
    
    async def mark_post_processed(self, post_data: dict, post_hash: str) -> int:
        """
        Отметить пост как обработанный (INSERT или UPDATE).
        Возвращает ID записи в БД.
        """
        async with self.pool.acquire() as conn:
            # UPSERT (INSERT ... ON CONFLICT UPDATE)
            result = await conn.fetchrow(
                """
                INSERT INTO processed_posts 
                    (post_hash, vk_post_id, owner_id, source_url,
                     text_hash, price_original, price_edited, images_count,
                     last_parsed_at)
                VALUES 
                    ($1, $2, $3, $4, $5, $6, $7, $8, NOW())
                ON CONFLICT (vk_post_id, owner_id) 
                DO UPDATE SET
                    text_hash = EXCLUDED.text_hash,
                    price_original = EXCLUDED.price_original,
                    price_edited = EXCLUDED.price_edited,
                    images_count = EXCLUDED.images_count,
                    last_parsed_at = NOW()
                RETURNING id
                """,
                post_hash,
                post_data.get('vk_post_id'),
                post_data.get('owner_id'),
                post_data.get('source_url'),
                self.compute_text_hash(post_data.get('text', '')),
                post_data.get('price_original'),
                post_data.get('price_edited'),
                len(post_data.get('images', []))
            )
            return result['id']
    
    async def mark_post_exported(self, post_id: int, targets: List[str]) -> None:
        """Отметить пост как выгруженный в указанные платформы"""
        async with self.pool.acquire() as conn:
            await conn.execute(
                """
                UPDATE processed_posts 
                SET is_exported = TRUE,
                    export_targets = $2,
                    exported_at = NOW()
                WHERE id = $1
                """,
                post_id, targets
            )
    
    async def log_export(self, post_id: int, target: str, external_id: str, 
                        status: str, error: str = None) -> None:
        """Записать в историю выгрузок"""
        async with self.pool.acquire() as conn:
            await conn.execute(
                """
                INSERT INTO export_history 
                    (post_id, target_platform, external_id, status, error_message)
                VALUES ($1, $2, $3, $4, $5)
                """,
                post_id, target, external_id, status, error
            )
    
    async def get_exported_posts_count(self, owner_id: str, days: int = 30) -> int:
        """Статистика: сколько постов выгружено за период"""
        async with self.pool.acquire() as conn:
            row = await conn.fetchrow(
                """
                SELECT COUNT(*) 
                FROM processed_posts 
                WHERE owner_id = $1 
                  AND is_exported = TRUE 
                  AND exported_at > NOW() - INTERVAL '%s days'
                """ % days,
                owner_id
            )
            return row['count']
    
    async def cleanup_old_records(self, days: int = 90) -> int:
        """
        Очистка старых записей (не выгруженных, старше N дней).
        Возвращает количество удалённых записей.
        """
        async with self.pool.acquire() as conn:
            result = await conn.execute(
                """
                DELETE FROM processed_posts 
                WHERE is_exported = FALSE 
                  AND last_parsed_at < NOW() - INTERVAL '%s days'
                """ % days
            )
            # Возвращаем количество удалённых (через GET DIAGNOSTICS в PL/pgSQL)
            return int(result.split()[-1]) if result else 0
```

# === cache/redis_cache.py ===
import redis.asyncio as redis
import json
from typing import Optional

class PostCache:
    """
    Redis-кэш для быстрого доступа к статусам постов.
    TTL: 24 часа для активных сессий парсинга.
    """
    
    def __init__(self, redis_url: str):
        self.redis = redis.from_url(redis_url, decode_responses=True)
    
    async def get_post_status(self, post_hash: str) -> Optional[dict]:
        """Быстрая проверка статуса из кэша"""
        data = await self.redis.get(f"post:{post_hash}")
        return json.loads(data) if data else None
    
    async def set_post_status(self, post_hash: str, status: dict, ttl: int = 86400):
        """Сохранение статуса в кэш"""
        await self.redis.setex(
            f"post:{post_hash}",
            ttl,
            json.dumps(status)
        )
    
    async def invalidate_user_cache(self, user_id: int):
        """Очистка кэша пользователя при изменении настроек"""
        keys = await self.redis.keys(f"user:{user_id}:*")
        if keys:
            await self.redis.delete(*keys)

### 3.5. Интеграция в основной пайплайн

```python
# === engine/vkpars_core.py (фрагмент) ===

class VKParsEngine:
    def __init__(self, vk_token: str, db_url: str, redis_url: str = None):
        self.parser = VKPostParser(vk_token)
        self.tracker = DuplicateTracker(db_url)
        self.cache = PostCache(redis_url) if redis_url else None
    
    async def process_pipeline(self, source_url: str, ...) -> Dict:
        # 1. Парсинг
        raw_posts = await self.parser.parse_wall(source_url)
        
        # 2. Фильтрация дубликатов
        new_posts = []
        for post in raw_posts:
            post_hash = self.tracker.compute_post_hash(post)
            
            # Проверка кэша (быстро)
            if self.cache:
                cached = await self.cache.get_post_status(post_hash)
                if cached and not cached.get('needs_reparse'):
                    continue  # Пропускаем, уже обработан
            
            # Проверка БД (точно)
            is_processed = await self.tracker.is_post_processed(
                post_hash, post['post_id'], post['owner_id']
            )
            
            if not is_processed or self.parse_config.show_exported:
                new_posts.append(post)
        
        # 3. Обработка новых постов
        for post in new_posts:
            post_hash = self.tracker.compute_post_hash(post)
            db_id = await self.tracker.mark_post_processed(post, post_hash)
            post['db_id'] = db_id
            
            # ... редактирование, выгрузка ...
            
            # 4. После успешной выгрузки
            await self.tracker.mark_post_exported(db_id, export_targets)
            await self.tracker.log_export(db_id, target, external_id, 'success')
            
            # Обновление кэша
            if self.cache:
                await self.cache.set_post_status(post_hash, {
                    'is_exported': True,
                    'exported_at': datetime.now().isoformat()
                })
        
        return {"processed": len(new_posts), ...}
```

## 🔑 2. Типы токенов ВКонтакте

| Тип токена | Как получить | Лимиты | Права | Для чего в VKPARS |
|------------|--------------|--------|-------|-------------------|
| **User Token** | OAuth 2.0 (пользователь) | 3 req/sec | Права пользователя | Парсинг стен, альбомов, товаров |
| **Group Token** | OAuth 2.0 (от имени группы) | 20 req/sec | Права группы | Выгрузка в свои группы |
| **Service Token** | Настройки VK App | 20 req/sec | Ограниченные | Фоновые задачи, уведомления |
| **Community Token** | Управление сообществом | 20 req/sec | Полные права группы | Публикация от имени группы |

> ⚠️ **Важно:** Для парсинга **чужих** групп достаточно User Token. Для выгрузки в **свои** группы нужен Group Token с правами на публикацию.

-- === schema/user_tokens.sql ===

CREATE TABLE user_tokens (
    id BIGSERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL,                     -- ID пользователя в VKPARS
    vk_user_id VARCHAR(32) NOT NULL,              -- ID пользователя в VK
    
    -- Токены
    access_token TEXT NOT NULL,
    expires_at TIMESTAMP WITH TIME ZONE,          -- NULL если offline-токен
    refresh_token TEXT,                           -- Для обновления
    
    -- Права (scopes)
    granted_scopes TEXT[],                        -- ['wall', 'photos', 'groups']
    
    -- Статус
    is_active BOOLEAN DEFAULT TRUE,
    last_used_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    -- Уникальность
    CONSTRAINT unique_user_vk UNIQUE (user_id, vk_user_id)
);

CREATE TABLE group_tokens (
    id BIGSERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES user_tokens(user_id),
    vk_group_id VARCHAR(32) NOT NULL,             -- ID группы в VK
    group_name VARCHAR(255),
    
    access_token TEXT NOT NULL,
    granted_scopes TEXT[],
    
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    
    CONSTRAINT unique_group UNIQUE (user_id, vk_group_id)
);

-- Индексы
CREATE INDEX idx_user_tokens_user ON user_tokens(user_id);
CREATE INDEX idx_user_tokens_active ON user_tokens(is_active);
CREATE INDEX idx_group_tokens_user ON group_tokens(user_id);

## 💻 4. Реализация Backend (Python/FastAPI)

### 4.1. OAuth-контроллер

```python
# === api/auth/vk_oauth.py ===
import httpx
from fastapi import APIRouter, Request, Response, HTTPException
from fastapi.responses import RedirectResponse
from urllib.parse import urlencode
import os

router = APIRouter(prefix="/auth/vk", tags=["authentication"])

VK_APP_ID = os.getenv("VK_APP_ID")
VK_APP_SECRET = os.getenv("VK_APP_SECRET")
VK_REDIRECT_URI = os.getenv("VK_REDIRECT_URI", "https://vkpars.ru/auth/vk/callback")
VK_OAUTH_URL = "https://oauth.vk.com/authorize"
VK_TOKEN_URL = "https://oauth.vk.com/access_token"

@router.get("/login")
async def vk_login():
    """
    Шаг 1: Перенаправление на VK OAuth
    """
    params = {
        "client_id": VK_APP_ID,
        "redirect_uri": VK_REDIRECT_URI,
        "display": "page",
        "scope": "wall,photos,market,groups,offline",
        "response_type": "code",
        "v": "5.131",
    }
    auth_url = f"{VK_OAUTH_URL}?{urlencode(params)}"
    return RedirectResponse(url=auth_url)

@router.get("/callback")
async def vk_callback(request: Request, code: str = None, error: str = None):
    """
    Шаг 2: Обработка callback от VK
    Обмен authorization code на access token
    """
    if error:
        raise HTTPException(status_code=400, detail=f"VK OAuth error: {error}")
    
    if not code:
        raise HTTPException(status_code=400, detail="Authorization code not provided")
    
    # Обмен code → token
    async with httpx.AsyncClient() as client:
        response = await client.post(VK_TOKEN_URL, data={
            "client_id": VK_APP_ID,
            "client_secret": VK_APP_SECRET,
            "redirect_uri": VK_REDIRECT_URI,
            "code": code,
        })
        
        if response.status_code != 200:
            raise HTTPException(status_code=400, detail="Failed to exchange code for token")
        
        token_data = response.json()
    
    # token_data содержит:
    # {
    #     "access_token": "...",
    #     "expires_in": 0,  # 0 = бессрочный (offline)
    #     "user_id": 123456,
    #     "email": "..." (если запрошен scope email)
    # }
    
    # Сохранение токена в БД
    await save_user_token(
        vk_user_id=str(token_data["user_id"]),
        access_token=token_data["access_token"],
        expires_at=None if token_data.get("expires_in") == 0 else datetime.now() + timedelta(seconds=token_data["expires_in"]),
        granted_scopes=["wall", "photos", "market", "groups", "offline"]
    )
    
    # Перенаправление на главную страницу VKPARS
    return RedirectResponse(url="https://vkpars.ru/dashboard")

@router.get("/groups")
async def get_user_groups(request: Request):
    """
    Получение списка групп пользователя для выбора куда выгружать
    """
    user_token = await get_current_user_token(request)
    
    async with httpx.AsyncClient() as client:
        response = await client.get("https://api.vk.com/method/groups.get", params={
            "access_token": user_token,
            "v": "5.131",
            "extended": 1,
            "filter": "admin"  # Только группы где пользователь админ
        })
        
        groups_data = response.json()
    
    return groups_data.get("response", {"items": []})

@router.post("/group/token")
async def save_group_token(request: Request, group_id: str):
    """
    Получение токена конкретной группы (для публикации от имени группы)
    """
    user_token = await get_current_user_token(request)
    
    async with httpx.AsyncClient() as client:
        response = await client.get("https://api.vk.com/method/groups.getToken", params={
            "access_token": user_token,
            "v": "5.131",
            "group_id": group_id
        })
        
        token_data = response.json()
    
    # Сохранение group token в БД
    await save_group_token(
        user_id=request.state.user_id,
        vk_group_id=group_id,
        access_token=token_data["response"]["access_token"],
        granted_scopes=["wall", "photos", "market"]
    )
    
    return {"status": "success"}
```

### 4.2. Менеджер токенов

```python
# === services/token_manager.py ===
import asyncpg
from typing import Optional, List
from datetime import datetime

class TokenManager:
    """Управление токенами ВКонтакте"""
    
    def __init__(self, db_pool: asyncpg.Pool):
        self.pool = db_pool
    
    async def get_user_token(self, user_id: int) -> Optional[str]:
        """Получить активный токен пользователя"""
        async with self.pool.acquire() as conn:
            row = await conn.fetchrow(
                """
                SELECT access_token FROM user_tokens
                WHERE user_id = $1 AND is_active = TRUE
                ORDER BY last_used_at DESC
                LIMIT 1
                """,
                user_id
            )
            return row["access_token"] if row else None
    
    async def get_group_token(self, user_id: int, group_id: str) -> Optional[str]:
        """Получить токен конкретной группы"""
        async with self.pool.acquire() as conn:
            row = await conn.fetchrow(
                """
                SELECT access_token FROM group_tokens
                WHERE user_id = $1 AND vk_group_id = $2 AND is_active = TRUE
                """,
                user_id, group_id
            )
            return row["access_token"] if row else None
    
    async def get_user_groups(self, user_id: int) -> List[dict]:
        """Получить список подключённых групп пользователя"""
        async with self.pool.acquire() as conn:
            rows = await conn.fetch(
                """
                SELECT vk_group_id, group_name, created_at
                FROM group_tokens
                WHERE user_id = $1 AND is_active = TRUE
                """,
                user_id
            )
            return [dict(row) for row in rows]
    
    async def revoke_token(self, user_id: int, token_type: str = "user") -> None:
        """Отзыв токена (выход из аккаунта)"""
        async with self.pool.acquire() as conn:
            if token_type == "user":
                await conn.execute(
                    "UPDATE user_tokens SET is_active = FALSE WHERE user_id = $1",
                    user_id
                )
            else:
                await conn.execute(
                    "UPDATE group_tokens SET is_active = FALSE WHERE user_id = $1",
                    user_id
                )
    
    async def update_last_used(self, user_id: int) -> None:
        """Обновить время последнего использования токена"""
        async with self.pool.acquire() as conn:
            await conn.execute(
                """
                UPDATE user_tokens 
                SET last_used_at = NOW() 
                WHERE user_id = $1 AND is_active = TRUE
                """,
                user_id
            )
```

## 🔒 6. Безопасность и хранение токенов

### 6.1. Шифрование токенов в БД

```python
# === services/encryption.py ===
from cryptography.fernet import Fernet
import os

class TokenEncryptor:
    """Шифрование токенов перед сохранением в БД"""
    
    def __init__(self):
        # Ключ должен храниться в ENV, не в коде
        self.key = os.getenv("TOKEN_ENCRYPTION_KEY").encode()
        self.fernet = Fernet(self.key)
    
    def encrypt(self, token: str) -> str:
        """Шифрование токена"""
        return self.fernet.encrypt(token.encode()).decode()
    
    def decrypt(self, encrypted_token: str) -> str:
        """Расшифровка токена"""
        return self.fernet.decrypt(encrypted_token.encode()).decode()

# Использование при сохранении
encrypted_token = TokenEncryptor().encrypt(user_access_token)
# Сохраняем encrypted_token в БД

# Использование при запросе к VK API
token = TokenEncryptor().decrypt(encrypted_token_from_db)
```

## ⚠️ 8. Важные замечания для команды

1. **Offline-токены:** Запрашивайте scope `offline` для бессрочных токенов (не требуют повторной авторизации)
2. **HTTPS обязательно:** VK OAuth требует HTTPS для redirect_uri (кроме localhost)
3. **Хранение токенов:** Никогда не логгируйте токены, шифруйте в БД
4. **Истечение токенов:** Проверяйте `expires_in` перед каждым запросом к API
5. **Rate limiting:** Учитывайте лимиты VK API (3 req/sec для user token)
6. **VK API версия:** Фиксируйте версию API (`v=5.131`), чтобы избежать breaking changes
