# VK Insights Analyzer (v1.1)

Интеллектуальная система парсинга, фильтрации, калькуляции наценок и экспорта постов из торговых сообществ ВКонтакте (например, рынков Садовод и Южные Ворота). Проект полностью перенесен в целевую среду сборки Vite + React 19 + TypeScript и адаптирован под жесткие требования Технического Задания (ТЗ).

---

## 📖 Обзор Архитектуры и Модулей

Архитектура приложения построена по модульному принципу с четким разделением ответственности:

### 1. Ядро управления состоянием (Centralized State Manager)
*   **Файл**: `/src/hooks/use-posts-store.tsx`
*   **Функция**: Централизованный React Context + Custom Hook. Управляет загруженными постами, фильтрами, сортировками, избранным, логами экспорта и конфигурацией цен.
*   **Персистентность**: Абсолютно все пользовательские действия (избранное, отредактированные тексты, ручные правки цен, пресеты экспорта, сессии токенов) автоматически синхронизируются с `localStorage` браузера.

### 2. Модуль интеграции с VK API (VK API Client)
*   **Файл**: `/src/lib/vk-api-client.ts`
*   **Функция**: Осуществляет прямые запросы к живым серверам VK API прямо из браузера через динамический обход CORS посредством **JSONP (`fetchVkJsonp`)**.
*   **Режим работы**:
    *   **Песочница (Sandbox)**: Полноценный оффлайн-режим с генерацией реалистичных торговых товаров для тестирования без авторизации и токенов.
    *   **Живой режим ВК**: Автоматический фоллбок на подписку (если стена закрыта для сторонних пользователей, бот попытается сам вступить в группу через `groups.join`), а также каскадный разбор вложений и привязка оригинальных ID фото.

### 3. Модуль Умного Анализа Текста (Text Intelligence Plugin)
*   **Директория**: `/src/plugins/text-intelligence/`
*   **Компоненты**:
    *   `index.ts`: Фасад для разбора сырых текстов.
    *   `cleaner.ts`: Автоматический клининг рекламного мусора, стоп-слов, ссылок и служебных символов.
    *   `rules.ts`: Системные регулярные выражения для безошибочного выцепления цен в разных валютах (RUB, USD, EUR, KZT, UE), выявления оптовых градаций и извлечения линеек размерных рядов.

### 4. Модуль Умного Анализа Изображений (Visual Intelligence Plugin)
*   **Директория**: `/src/plugins/visual-intelligence/`
*   **Функции**: Построение перцептивного хэша (**pHash**) изображений на клиенте и использование распределенного хранилища **IndexedDB** для мгновенного поиска визуальных дубликатов (товаров с одинаковым фото от разных поставщиков).

### 5. Менеджер сессий VK (VK Session Manager)
*   **Директория**: `/src/plugins/vk-manager/`
*   **Функции**:
    *   **Очередь запросов (Request Queue)**: Ограничитель RPS для защиты от блокировок по лимитам запросов к VK API.
    *   **Панель Bot-настроек**: Установка автоматических водяных знаков бренда, индивидуальных подписей аккаунтов на выгружаемые посты и применение настроек приватности на стене донора.

## ⚡ Строгое соблюдение ТЗ (Валидация и Лимиты)

Приложение включает в себя жесткие программные проверки, описанные в Техническом Задании торговой платформы:

1.  **Лимит сессионной выборки (до 10 000 постов)**:
    *   *Реализация*: На уровне загрузчика в `/src/lib/vk-utils.ts` принудительно обрезается сверхнормативный хвост импортированного массива постов до `10,000` записей для гарантированного предотвращения утечек памяти браузера. На UI-слое для бесконечной прокрутки табличного вида интегрирован `react-virtuoso`, обеспечивающий виртуализацию DOM.
2.  **Валидация файлов (до 10 МБ)**:
    *   *Реализация*: Внутри компонента `/src/components/app/file-uploader.tsx` константа `MAX_FILE_SIZE = 10 * 1024 * 1024` блокирует загрузку файлов больше 10МБ на этапе парсинга с отображением кастомной нотификации о превышении размера.
3.  **Конфигурационные пресеты выгрузки (до 5 штук)**:
    *   *Реализация*: При сохранении конфигураций колонок для экспорта в `.csv` (`saveExportProfile` в `use-posts-store.tsx`) массив профилей принудительно усекается методом `.slice(0, 5)`. Это обеспечивает соответствие ТЗ по количеству шаблонов выгрузки в один клик.
4.  **Логирование истории выгрузок (до 50 последних записей)**:
    *   *Реализация*: Массив системных логов экспорта в ВК в реальном времени ограничивается до `50` последних событий, предотвращая перегрузку хранилища `localStorage`.

## 🚀 Установка и Запуск в Среде

Приложение легко запускается в среде Node.js с поддержкой Vite.

### Запуск в режиме разработки:
```bash
npm run dev
```

### Сборка production-версии:
```bash
npm run build
```
