# 📘 VK Insights Analyzer — Архитектура и Документация Плагинов

## 📋 Статус интеграции плагинов (Интегрированы на 100%)
Все разработанные плагины полностью подключены, синхронизированы с основным стейт-менеджером (`use-posts-store.tsx`) и интерактивными панелями управления:

### 1. `vk-manager` (Оркестратор роботов) — **ПОДКЛЮЧЕН**
* **Где используется:**
  * `src/components/app/vk-integration.tsx` — визуальная консоль "SMM-Оркестратора": управление профилями, запуск автопилота, кастомизация наценок, индивидуальная подпись и настройки приватности.
  * `src/components/app/table-toolbar.tsx` — выпадающий селектор быстрых пресетов коммерческих групп (Одежда/Обувь Садовод).
  * `src/hooks/use-posts-store.tsx` — обогащение постов перед выгрузкой (автоматическое наложение водяных знаков бренда, индивидуальных подписей профиля) и передача спец-параметров публикации в VK API.
* **Функционал:**
  * **Пул аккаунтов (Token Pool):** Автоматическая ротация токенов при обнаружении блокировки или лимита запросов.
  * **RPS-Предохранитель (Limit Queue):** Сетевая очередь с аппаратной задержкой `350мс` (не более 3 запросов в секунду), предохраняющая от блокировки API.
  * **Настройки приватности (Privacy):** Тонкая настройка постов (доступность только для друзей, закрытие комментариев, публикация "без уведомлений (тихий режим)" и пометка рекламы `mark_as_ads`).
  * **Коммерческая наценка:** Индивидуальное масштабирование цен (проценты или фиксированный рублевый зазор).

---

### 2. `text-intelligence` (NLP Парсер текста) — **ПОДКЛЮЧЕН**
* **Где используется:**
  * `src/hooks/use-posts-store.tsx` — при загрузке постов со стены или импорте из JSON, прогоняет текст через NLP-конвейер разбора.
  * `src/components/app/gallery-viewer.tsx` — интерактивная ручная правка и очистка текста во время инспекции товара.
* **Функционал:**
  * **Очистка спама (`cleaner.ts`):** Автоматическое вырезание нежелательных номеров телефонов, гиперссылок типа `vk.com/...`, приглашений к конкурентам и рекламного шума.
  * **Парсер цен (`rules.ts`):** Выделяет розничные и оптовые цены на основе комплексных регулярных выражений, распознает форматы `руб`, `₽`, `тенге`, `у.е.` и диапазоны (забирая минимальное значение).
  * **Выявление размеров (`lexicon.ts`):** Извлечение линеек размеров одежды (например, `42, 44, 46-48`) и обуви.
  * **Местонахождение поставщика:** Маркировка павильонов Садовода (например: `22-45`, `СТ6-13`).
  * **Мульти-сплиттинг (`splitMultiPosts`):** Интеллектуальный разделитель. Если поставщик опубликовал 10 фото и написал в один пост цены на три разных товара по пунктам "1., 2., 3.", парсер автоматически делит один физический пост на три независимые карточки с индивидуальными ценами и распределенными фото.

---

### 3. `visual-intelligence` (Анти-Дубликаты) — **ПОДКЛЮЧЕН**
* **Где используется:**
  * `src/components/app/gallery-viewer.tsx` — расчет перцептивных хешей (`pHash`) картинок, персистентное кэширование и поиск дубликатов при просмотре карточки товара.
* **Функционал:**
  * **Перцептивный Хеш (`pHash`):** Расчет визуального отпечатка изображения на базе фрактального сжатия и дискретно-косинусного преобразования, устойчивый к изменению размера или сжатию JPEG.
  * **База на IndexedDB (`db.ts`):** Хранит хэши картинок локально в браузере. База работает мгновенно даже на тысячах постов.
  * **Сверка сходства (Similarity Match):** Позволяет находить одинаковые товары у разных поставщиков. Показывает точный процент совпадения картинок. Выдает предупреждение в интерфейсе, защищая от спама в паблик.

## 🚀 Текущий этап разработки приложения
Приложение полностью скомпилировано, оптимизировано для работы на клиенте без жестких серверных зависимостей и представляет собой **полноценное рабочее SMM-место контент-менеджера**:

1. **Два режима получения данных:**
   * **Оффлайн-анализ (Offline-First):** Импорт raw JSON архивов (полученных через парсеры или `wall.get`) размером до 10 МБ с мгновенной обработкой до 10 000 постов благодаря виртуализации списка (`react-virtuoso`).
   * **Онлайн-сбор:** Направленный парсинг стен групп Садовода по домену или ID (например, `shoes_wholesale`, `opt_sadovod` и т.д.) через `VK API` со встроенным авто-вступлением в закрытые группы, если стена доступна только подписчикам.
2. **Расширенные фильтры и Сортировка:** Моментальная фильтрация по лайкам, просмотрам, датам, ценовым барьерам. Сортировка всей базы ("живая сортровка" за миллисекунды).
3. **Статистика & Аналитика (`stats-panel.tsx`):** Сводная аналитика по ценам, наполнению размерами, вовлеченности аудитории поста (ER).
4. **Тонкая SMM-конфигурация публикации:** Редактирование изображений, очистка подписей, подготовка наценки и экспорт в целевую группу ВК с учетом SMM-роботизации.

## 🛠️ Описание ключевых функций технического ядра

### 🎯 Конвейер NLP разбора (Text Intelligence)
Каждый сырой пост пропускается через фасадную функцию `parse`:
```typescript
SmartParsedPost = TextIntelligence.parse(rawPost);
```
1. Текст пропускается через `cleanText` (удаление смайликов-мусора, ссылок, чужих хэштегов).
2. Выделяется первая строка как заголовок товара (`title`).
3. Поиск павильона поставщика по шаблонам `VENDOR_LOCATION_PATTERNS` (павильоны, линии, корпуса).
4. Извлечение цен с классификацией на оптовую и розничную.
5. Извлечение размерного ряда.

При наличии признаков группового поста срабатывает `TextIntelligence.splitMultiPosts(parsed)`:
```typescript
const splittedItems: SmartParsedPost[] = TextIntelligence.splitMultiPosts(parsedItem);
```
Она нарезает его на суб-товары, разделяя фото и подписи, предотвращая ручную рутину контент-менеджера.

### 🛡️ Алгоритм предотвращения дубликатов постов (Visual Intelligence)
Реализовано сравнение картинок на базе побайтового расстояния Хэмминга.
1. При первой загрузке картинок вычисляется их pHash (`VisualIntelligence.compute(url, postId)`).
2. Запись о хэше сохраняется в IndexedDB (`vk-image-hashes-db`).
3. При открытии карточки в Галерее запускается:
   ```typescript
   const duplicates = await VisualIntelligence.findDuplicates(pHash, currentPostId, 80);
   ```
   Если найдено совпадение выше 80%, UI помечает пост предупреждением ⚠️ "Визуальный дубликат ранее выгруженного товара" с кликабельной ссылкой на оригинальный пост.

### 🤖 Автоматическое вступление в группы (Failover защиты)
При запуске парсинга чужих стен (например, поставщиков Садовода) часто возникает системная ошибка:
`Access denied: this wall available only for community members`

В нашей библиотеке `vk-api-client.ts` реализован автоматический обход:
```typescript
if (isCommunityMemberError && !isRetry) {
   // Попытка автоматически подписаться на целевую группу через groups.join
   await fetchVkJsonp('groups.join', { group_id: targetGroupId, ... });
   // Пауза 1.2 сек на обновление сессии и повторный запуск
   return this.fetchWallPosts(ownerIdOrDomain, ..., true);
}
```
Если аккаунт пользователя не заблокирован, робот сам бесшовно подпишется на группу и продолжит сбор за полторы секунды!
